# 日镜账

中文名：**日镜账** · 前缀 `daysnap` · 端口 **6600 / 11600**

## 骨架

**日终余额抽取 → 周期快照落行 → 变动流水回放核对 → 断档/跳变检出 → 快照与回放差额清单**

皮：收单/结算账户的日终余额镜。去皮是 **周期快照事实 + 流水回放守恒 + 断档跳变检出**，不是银行核心 CRUD、不是日结封账锁定、不是双边齐账。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6600
# 台面 → 一键冒烟 → 周期快照有行 → 差额清单为空（或仅看最新回放批）
```

## 切点归属口径（全局唯一：乙 · 冻结列永冻）

本仓库在「切点凭证表为准」（甲）与「流水行归属列永冻」（乙）之间只贯彻 **乙口径**：

- 装载事务用 `BEGIN IMMEDIATE` 锁住切点凭证，按当前凭证计算一次归属日，并写入 `变动流水.归属日`（另有生成列 `归属营业日`）。
- `抽取`、`回放`、流水查询只读取 `COALESCE(NULLIF(归属日,''), 营业日)`，不按抽取时钟或当前切点重算；抽取阶段没有任何改写归属的 SQL。
- SQLite 触发器 `禁止冻结归属日改写` 阻止已冻结的非空归属日被 UPDATE。
- 切换切点只产生新的 `切点凭证`；之后的新流水号走新界。旧流水号重放只能幂等拒绝或按原批次原样返回，归属日保持不变，并写 `切点重放审计`（含「若按当前凭证重算会落到哪一天」用于区分口径）。
- 切点切换与装载竞争 SQLite 写锁；`busy_timeout=5000` 后仍失败则返回 409 / `失败闭=true`，不会猜测切点或产生同笔双归属。

只读接口：

```http
GET /api/切点归属?流水号=流-切-前-001
GET /api/切点归属/流-切-前-001
```

返回字段包含 `流水号`、`归属日`、`凭证/凭证编号`、`冻结列`、`valid`、`架构`、`归属可变=false`、`mutable=false`。兼容别名：`/api/归属/{流水号}`、`/api/流水归属/{流水号}`、`/api/attribution/{serial}`、`/api/cutoff/attribution?serial=...`。`GET /api/流水?营业日=...` 也使用同一冻结归属谓词，不会按申报营业日另开一口径。

切点凭证与审计：

```http
GET  /api/切点凭证
GET  /api/切点凭证/当前
POST /api/切点凭证        # {"切点时刻":"23:00","时区":"UTC","凭证编号":"..."}
GET  /api/切点重放审计?流水号=...
```

夹具：

- `fixtures/切点前后夹具.json`：23:00 前后各一笔，归属 2026-11-25 / 2026-11-26；抽取两日并回放均无差额。
- `fixtures/切点重放夹具.json`：切到 22:00 后重放同流水号；当前凭证重算会改变第一笔，但冻结归属不变。
- `fixtures/切点并发夹具.json`：同笔并发装载与切点切换，断言只有一行、一个归属。
- 同名英文版：`cutoff-before-after.json`、`cutoff-replay-old-payload.json`、`cutoff-concurrent-load-switch.json`。
